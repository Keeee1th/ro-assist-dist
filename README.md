# RO 助手脚本分发

本仓库公开发布 RO 助手正式版/实验版，以及无限道场、物品高亮、环境探测、对话转储四个可选脚本。辅助脚本需玩家自行安装，不会由助手自动下载。

环境探测插件把角色与诊断信息发往用户本机 127.0.0.1；对话转储可能包含运行时隐私，分享前请自行检查。

本地物品接收器源码位于 `tools/`，使用 `node tools/ro-item-capture-receiver.cjs` 启动；仅绑定 127.0.0.1:8793，并将记录写入启动目录下的 `.dsh-work/ro-items/events.jsonl`。采集数据不会发布到本仓库。

公开产物不包含账号配置、采集日志或个人数据。
